# 待机动画素材

- `sprites.png`：透明背景精灵图集，9x5 排列，每帧 384x480。
- `animation.tres`：SpriteFrames 资源，12 fps，包含两个待机剪片：
  - `idle_01`：从站立转入待机的完整动画，45 帧，不循环。
  - `idle_02`：持续待机循环，默认复用 `idle_01` 最后 0.5 秒（最后 6 帧），
    按 x → 末帧 → 回到 x 对称往返播放（共 11 帧）；
    角色查看器中可用“02截取时长”滑杆调整截取秒数，再点“保存 02”写回本资源。
- 来源：`素材/lxq/Idle/animation_original01.mp4`（白底视频抠像生成）。
